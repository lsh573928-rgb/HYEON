# 삽 진화 애니메이션 (나무 → 돌 → 철 → 다이아몬드)

마인크래프트 스타일 픽셀아트 삽이 8초 동안 진화하는 영상입니다.

| `minecraft_shovel_evolution_silent.mp4` | 같은 영상의 무음본(배경음악을 따로 깔 때), 4.85 MB |

## 타임라인

| 시간 | 연출 |
|---|---|
| 0.0–2.0초 | 나무 삽 등장(살짝 커지며 떠오름), 위아래로 떠다니고 ±2.5° 미세하게 흔들림 |
| 2.0초 | 하얗게 달아오르며 떨림 → 섬광 → **돌 삽** 교체, 나무 파편·돌 불꽃 파티클, 충격파 고리, 화면 흔들림 |
| 4.0초 | 흰색 픽셀 광선 섬광 → **철 삽**, 금속 빛 띠가 손잡이→삽날로 훑고 삽날 위 반짝임 |
| 6.0초 | 청록 빛 물결이 퍼지고 고리 2겹, 회전 광선, 파티클 대량(위로 떠오르는 빛 알갱이 포함) → **다이아몬드 삽** |
| 6.0–8.0초 | 반짝임이 점점 줄어 7.6초에 모두 사라지고, 흔들림도 멈춰 마지막 프레임은 정지·정렬 상태로 선명하게 |

배경: 어두운 돌 블록 동굴 벽(석탄·철·다이아 광석 약간), 양옆 횃불이 미세하게 깜박이고 먼지 알갱이가 천천히 떠오릅니다.
삽 재질에 맞춰 벽에 비치는 빛 색이 바뀝니다(나무 따뜻한 빛 → 다이아 청록 빛).

## 효과음 (`source/sfx.py`)

소리 파일을 쓰지 않고 전부 NumPy로 합성했습니다. 시각은 `render.py`의 전환 시각과 반짝이 목록을 그대로 읽으므로 화면과 어긋나지 않습니다.
마지막에 동굴 잔향(약 2.9초)을 입힙니다.

| 시간 | 소리 |
|---|---|
| 전체 | 낮게 깔린 동굴 저음, 물방울 '똑' 3번(1.15·3.45·5.25초), 좌우 횃불 타닥 소리 |
| 0.0–0.4초 | 등장 '휘익' + 칩튠 '뿅' |
| 각 전환 직전 0.32초 | 반음씩 오르는 칩튠 음 + 바람 상승음(기 모으기) |
| 2.0초 | 돌: 둔탁한 '쿵' + 나무 부서지는 소리 + 자갈 후두둑 |
| 4.0초 | 철: '쿵' + 금속 '챙'(비조화 배음, 1.5초 울림) + 빛 띠 '쉭' + 반짝 소리 |
| 6.0초 | 다이아: 가장 큰 '붐' + 수정 화음(E장조) + 칩튠 팡파르 + 반짝 소리 10여 개 + '쉭' 2번 |
| 7.75–8.0초 | 페이드아웃(끊김 방지) |

음량 크기 순서는 다이아 충격음 > 돌 > 철 > 기 모으기 > 바탕입니다. 소리 크기는 `sfx.py`의 각 함수에서 `m.put(..., gain)` 값을 바꾸면 됩니다.

## 품질 처리

- **텍스처**: 16×16 픽셀아트를 직접 찍었습니다(`source/pixelart.py`). 네 삽은 하나의 모양 틀에서 색표만 바꿔 만들어서
  실루엣·중심축·크기가 픽셀 단위로 같습니다(코드가 검사함).
- **확대**: 텍스처 1픽셀 = 화면 52px. 화면 픽셀마다 텍스처 좌표를 역계산해 가장 가까운 텍셀 색을 그대로 가져옵니다(nearest).
  회전·크기 출렁임이 있는 프레임에서만 텍셀 경계 1픽셀을 2×2 초표본으로 정리하고, 텍셀 안은 항상 단색입니다.
- **위치·크기 고정**: 네 삽 모두 같은 기준점(모양 외곽 상자 중심)을 화면 중앙에 놓고 같은 52px 배율로 그립니다.
- **인코딩**: RGB → BT.709 yuv420p 변환을 명시하고 색공간 태그를 붙였습니다(CRF 14, `-tune animation`, faststart).

```
f150 (5.0s)   기대 iron    → 판정 iron     텍셀 53개 평균오차 1.26 최대 3.0

```

대표 프레임은 MP4를 다시 디코딩해서 뽑습니다. 삽의 텍셀 53개 각각의 중심 색을 원본 텍스처 색과 비교한 결과,
오차가 최대 3/255여서 압축 후에도 색이 번지거나 뭉개지지 않았습니다. 네 재질 중 가장 가까운 것도 각각 기대한 재질과 맞았습니다.

## 다시 만들기

```bash
cd source
python3 pixelart.py      # textures/ 에 16x16 원본과 x16 확대본 저장
python3 render.py        # ../minecraft_shovel_evolution_silent.mp4 무음 영상(약 3분, CPU만)
python3 sfx.py           # ../audio/sfx.wav 합성 → 무음본에 입혀 ../minecraft_shovel_evolution.mp4 (2초)
python3 stills.py        # ../preview.png, ../thumbnail.png
python3 verify.py        # ffprobe 규격(영상·소리) + 대표 프레임 추출 + 텍셀 색 대조

# 세로판(1080x1920): 같은 타임라인·효과음, 배치만 다름(frames/vertical/에 검증 결과)
python3 render.py --vertical && python3 sfx.py --vertical && python3 verify.py --vertical
python3 render.py --still 60 180 --out-dir /tmp/x   # 특정 프레임만 PNG로
```

필요: Python 3.11+, NumPy, Pillow, FFmpeg(libx264). OpenCV는 쓰지 않습니다.

### 정식 텍스처로 바꿔 끼우기(선택)

본인이 정식으로 가진 Minecraft Java Edition 리소스에서
`assets/minecraft/textures/item/{wooden,stone,iron,diamond}_shovel.png` 4장을 한 폴더에 꺼내 두고 아래처럼 실행하면 됩니다.

```bash
python3 render.py --textures <그 폴더>
python3 stills.py <그 폴더>
```

공식 텍스처는 Mojang 저작물이므로 이 저장소에는 넣지 않았습니다.
