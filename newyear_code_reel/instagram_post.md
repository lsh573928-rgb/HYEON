| 영상(효과음만) | `newyear_code_reel_fx.mp4` — 가락 없이 효과음만. 인스타가 음원을 자동 인식해 표시하거나 막을 때 쓰는 예비본 |

프로필 격자에는 맺는 말("헛삽질은 없었습니다")이 보이는 편이 낫습니다. `cover.png`는 격자(3:4)와 피드(4:5)로 잘려도 글자가 남도록 맞춰 두었습니다.

## 올리는 순서

1. 사진 앱에 `newyear_code_reel.mp4`와 `cover.png`를 저장합니다.
2. 인스타그램 → 만들기 → 릴스 → 영상 선택. **자르기·속도·필터는 건드리지 않습니다**(끝과 처음이 이어지도록 만든 영상이라 길이를 자르면 반복 재생이 끊깁니다).
3. 소리
   - 그대로 올리면 영상에 들어 있는 소리(원본 오디오)가 쓰입니다. 이 판을 추천합니다 — 화면의 동작이 전부 음악 박자(120bpm)에 맞춰져 있습니다.
   - 유행 음원을 쓰고 싶으면 `newyear_code_reel_silent.mp4`를 올리고 앱에서 음원을 고릅니다. 박자가 120bpm에 가까운 곡이면 동작이 얼추 맞습니다.
4. 자동 자막(캡션 스티커)은 끕니다. 화면에 이미 글자가 많습니다.
5. 커버 → 카메라 롤에서 추가 → `cover.png`. 프로필 격자 미리보기에서 글자가 잘리지 않는지 확인합니다.
6. 캡션을 붙여 넣고 게시 → 바로 첫 댓글을 달고 고정합니다.
7. 스토리에 공유하고, Threads에는 같은 영상에 캡션 첫 두 줄만 올립니다.

## 게시 전 확인(사실 확인)

캡션에 쓴 말은 전부 `source/verify.py`가 실제로 돌려서 확인합니다. 대본이나 숫자를 바꿨다면 캡션도 같이 고쳐야 합니다.

| 캡션의 말 | 확인 방법 |
|---|---|
| 365를 100으로 줄이면 4월 10일에서 멈춘다 | 대본을 `me.삽질(100)`으로 바꿔 렌더 → 흙더미 높이·날짜 |
| 7번째 줄을 지우면 2027년이 안 온다 | `say("수고했어")` 줄을 뺀 대본 → 연도판이 2026에 머묾 |
| 눈 300송이 중 금색 한 송이 | `engine/fx.js`의 눈 그리기: 마지막 번호 한 송이만 금색 |
| 2026년은 전부 글자, 2027년에 진짜가 된다 | `engine/stage.js`의 '글자 세상'(별·눈·산·집·삽·질)과 `reveal` |
| 불꽃 12발 중 삽 모양 한 발 | 시각표(`build/events.json`)의 불꽃 12건 중 모양(shape) 1건 |
| 그림도 소리도 전부 코드 | 그림 파일·소리 파일 없이 `source/`의 코드만으로 다시 만들어짐 |

"코드 10줄이 영상을 만들었다"고 쓰지는 않았습니다. 화면의 10줄은 **장면 대본**이고, 그 대본을 읽어 그리는 엔진(`source/engine/`)이 따로 있습니다.

다른 후보 문구

- 낚는 말: `올해 한 게 없는 것 같아서 / 코드로 연말정산 해봄` · `새해가 안 넘어가는 이유 / 6번째 줄에 있습니다`
- 맺는 말(부드럽게): `헛삽질은 없었어요 / 올해도 수고했어요`

## 솔직한 안내

좋아요 수는 약속할 수 없습니다. 대신 이 갈래 영상에서 통하는 장치는 다 넣었습니다.

- 첫 프레임이 이미 완성 장면 + 궁금증을 남기는 한 줄("6번째 줄에서 에러 납니다")
- 소리를 꺼도, 코드를 안 읽어도 줄거리가 읽힘(연도판 밑 '수고했어' 빈칸 → 빨간 도장 → 체크, 헛삽질 12 → 0)
- 보낼 이유("나 올해 뭐 했지" 하는 친구)와 댓글 달 틀(`say("____")`)
- 레퍼런스의 "글자로 그린 그림"을 줄거리에 묶음: 2026년은 사물을 제 이름 글자로 그리고(눈·별·산·삽질), 2027이 되는 순간 진짜 그림이 됨
- 다시 볼 거리(금색 눈 한 송이, 삽 모양 불꽃, 달마다 붙는 말, 2026.12.31 → 2027.01.01)
- 끝이 처음으로 이어지는 반복 재생

나머지는 올리는 쪽에서 갈립니다 — 12월 20일~31일 사이 평일 저녁, 올린 뒤 한 시간 동안 댓글에 바로 답하기, 스토리 공유.
레퍼런스 릴스(글자로 그린 애니메이션 + 그 코드)는 보내 주신 화면 갈무리로 참고했습니다. 남의 캐릭터나 영상은 쓰지 않고, 캐릭터·그림·소리 모두 새로 만들었습니다.
