## 올리는 순서

1. 사진 앱에 `newyear_code_reel.mp4`와 `cover.png`를 저장합니다.
2. 인스타그램 → 만들기 → 릴스 → 영상 선택. **자르기·속도·필터는 건드리지 않습니다**(끝과 처음이 이어지도록 만든 영상이라 길이를 자르면 반복 재생이 끊깁니다).
3. 소리 — 아래 '음악 고르기'를 보고 정합니다. 추천은 영상에 든 소리 그대로(원본 오디오).
4. 자동 자막(캡션 스티커)은 끕니다. 화면에 이미 글자가 많습니다.
5. 커버 → 카메라 롤에서 추가 → `cover.png`. 프로필 격자 미리보기에서 글자가 잘리지 않는지 확인합니다.
6. 캡션을 붙여 넣고 게시 → 바로 첫 댓글을 달고 고정합니다.
7. 스토리에 공유하고, Threads에는 같은 영상에 캡션 첫 두 줄만 올립니다.

## 음악 고르기

**추천: 첫 게시는 자체 음악(`newyear_code_reel.mp4`) 그대로.**

- 웃음 포인트가 소리에 걸려 있습니다. 9초에 `year += 1`이 오류 나는 순간 음악이 뚝 끊기고, "수고했어"부터 다시 살아납니다. 유행 곡을 깔면 이 장면이 사라집니다.
- 화면 동작 전부(연도판 착지, 삽질 12번, 카운트다운, 2027 '철컥', 불꽃)가 120bpm 박자에 맞춰져 있고, 음악도 같은 박자로 만들었습니다.
- 곡은 저작권이 끝난 옛 가락 〈석별의 정〉을 코드로 합성한 것이라 공무원 계정에 올려도 문제가 없습니다.
- 퍼지면 '삽질하는 토목직 · 원본 오디오'로 소리가 남아, 그 소리로 다른 사람이 영상을 만들 때 계정이 같이 알려집니다.

**유행 곡을 쓰고 싶다면**

- 유행 곡 파일을 영상에 직접 넣지 않습니다. 저작권 때문에 소리가 꺼지거나 게시가 막힐 수 있습니다.
- `newyear_code_reel_fx.mp4`(효과음만)를 올리고, 인스타 앱의 음악 고르기에서 곡을 넣은 뒤 곡 음량을 30~40%로 낮춥니다. 실행음·'철컥'·불꽃 소리는 살아 있습니다.
- 곡 옆에 ↗(급상승) 표시가 붙은 것 중 밝고 120bpm 안팎인 곡이면 화면 박자와도 얼추 맞습니다.
- 계정이 '비즈니스'면 앱에서 유행 곡이 안 보일 수 있습니다. 그럴 땐 자체 음악판으로 올립니다.

**순서 제안:** 첫 게시는 자체 음악판 → 반응을 보고 며칠 뒤 스토리나 두 번째 게시물로 효과음판 + 유행 곡.

## 게시 전 확인(사실 확인)

캡션에 쓴 말은 전부 `source/verify.py`가 실제로 돌려서 확인합니다. 대본이나 숫자를 바꿨다면 캡션도 같이 고쳐야 합니다.

| 캡션의 말 | 확인 방법 |
|---|---|
| 365를 100으로 줄이면 4월 10일에서 멈춘다 | 대본을 `me.삽질(100)`으로 바꿔 렌더 → 흙더미 높이·날짜 |
| 7번째 줄을 지우면 2027년이 안 온다 | `say("수고했어")` 줄을 뺀 대본 → 연도판이 2026에 머묾 |
| 왼쪽은 전부 글자, 2027에 칸이 8px → 5px | `engine/newyear.js`의 `ascii()`(`const cell = env.year > env.year0 ? 5 : env.cell`) |
| 오른쪽은 진짜 코드 | 둘째 칸에 뜨는 글자 = 엔진이 돌리는 `newyear()` 함수 원문(`Function.toString`) |
| 불꽃 12발, 달마다 한 발, 마지막은 삽 모양 | 시각표(`build/events.json`)의 불꽃 12건 — 쏘는 순서대로 달(band) 0~11, 모양(shape) 1건 |
| 그림도 소리도 전부 코드 | 그림 파일·소리 파일 없이 `source/`의 코드만으로 다시 만들어짐 |

"코드 10줄이 영상을 만들었다"고 쓰지는 않았습니다. 화면의 10줄은 **장면 대본**이고, 그 대본을 읽어 그리는 엔진(`source/engine/`)이 따로 있습니다.

## 솔직한 안내

좋아요 수는 약속할 수 없습니다. 대신 이 갈래 영상에서 통하는 장치는 다 넣었습니다.

- 첫 프레임이 이미 완성 장면 + 궁금증을 남기는 한 줄("6번째 줄에서 에러 납니다")
- 소리를 꺼도, 코드를 안 읽어도 줄거리가 읽힘(연도판 밑 '수고했어' 빈칸 → 빨간 도장 → 체크, 헛삽질 12 → 0)
- 보낼 이유("나 올해 뭐 했지" 하는 친구)와 댓글 달 틀(`say("____")`)
- 레퍼런스처럼 왼쪽은 글자 그림, 오른쪽은 실제로 실행되는 코드(디버거 막대·실시간 값·터미널). 오류의 원인(`env.thanked = false`)까지 코드에서 보임
- 2027이 되는 순간 '해상도 업'(칸 8px → 5px) — 새해 = 업그레이드
- 다시 볼 거리(삽 모양 불꽃, 달마다 붙는 말, `d`가 365까지 오르는 반복문, 2026.12.31 → 2027.01.01)
- 끝이 처음으로 이어지는 반복 재생

나머지는 올리는 쪽에서 갈립니다 — 12월 20일~31일 사이 평일 저녁, 올린 뒤 한 시간 동안 댓글에 바로 답하기, 스토리 공유.
레퍼런스 릴스(글자로 그린 애니메이션 + 그 코드)는 보내 주신 화면 갈무리로 구성만 참고했습니다. 남의 캐릭터나 영상은 쓰지 않고, 캐릭터·그림·소리 모두 새로 만들었습니다.
