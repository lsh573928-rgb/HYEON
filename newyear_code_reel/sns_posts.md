## 인스타그램 (릴스)

```
올해 삽질 연말정산 해봤습니다.
삽질 365번, 헛삽질 0건.

근데 새해로 안 넘어가더라고요.
6번째 줄에서 계속 에러가 나서 봤더니
"수고했어" 한 줄이 빠져 있었습니다.

올해 나한테 그 말 한 번도 안 했더라고요 ㅎㅎ

say("____") 빈칸에 올해의 나한테 한마디 남겨주세요.
저는 say("수고했어") 했습니다.

올해도 수고 많으셨어요. 새해 복 많이 받으세요 🙇

#연말 #새해인사 #2027 #수고했어 #직장인 #코딩 #클로드코드 #삽질하는토목직
```

```

```

## 스레드

```
연말이라 AI랑 같이 영상 하나 만들었어요.

삽질 365번 해서 흙더미를 쌓았는데
새해로 안 넘어가요. 에러 사유: "수고했어" 누락.

그 한 줄 넣었더니 그제서야 2027이 되더라고요.

왼쪽 그림도, 음악도 전부 코드로 만든 거라
만들면서 저도 한 백 번은 삽질했습니다 ㅋㅋ

올해 다들 수고했어요.
```

이어 쓰는 글(선택, 댓글처럼 붙이기)

```
만든 방법이 궁금하신 분들께:
오른쪽 코드가 진짜로 왼쪽 그림을 그립니다.
365를 100으로 바꾸면 4월에서 멈추고,
"수고했어" 줄을 지우면 끝까지 2026년에 갇혀요.
```

## 유튜브 쇼츠 (삽질하는 AI)

제목

```
새해가 안 와서 에러 로그 봤더니… #shorts
```

설명

```
삽질 365번 하고 새해로 넘어가려는데 6번째 줄에서 에러가 났습니다.
사유: "수고했어" 누락.

왼쪽 ASCII 그림, 오른쪽 실행되는 코드, 배경음악(석별의 정 오르골)까지
전부 AI랑 같이 코드로 만들었습니다. 그림 파일·음원 파일은 하나도 안 썼어요.

올해 자신한테 수고했다는 말, 하셨나요?
댓글에 say("____") 로 한마디 남겨주세요.

#shorts #연말 #새해 #코딩 #ASCII #AI #클로드코드 #삽질하는AI
```

고정 댓글

```
올해 저의 삽질은 이 영상 하나 만드는 데 다 쓴 것 같습니다…
그래도 헛삽질은 0건! 다들 새해 복 많이 받으세요 🙏
```

### 올리는 순서 팁
- 인스타 → 같은 날 스레드(영상 첨부) → 다음 날 유튜브 쇼츠. 하루씩 띄우면 각 채널에서 따로 반응을 볼 수 있습니다.
- 12월 20~31일 평일 저녁 7~9시쯤이 무난합니다.
- 올린 뒤 첫 1시간은 댓글에 바로 답하기 — `say(...)` 댓글엔 "실행 완료 ✓" 같은 말투로.
