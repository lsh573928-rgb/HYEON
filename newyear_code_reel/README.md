# 새해 코드 릴스 — "헛삽질은 없었습니다" (2026 → 2027)

왼쪽에는 영상, 오른쪽에는 그 영상을 움직이는 코드가 한 줄씩 찍히는 16초짜리 인스타그램 릴스입니다.
그림 파일·소리 파일 없이 전부 코드로 만들었습니다.

## 줄거리 (화면 오른쪽의 대본 = `source/script.js`)

```python
year = 2026            # 연도판이 내려앉는다. 밑에는 비어 있는 '수고했어' 확인란
me = 삽질러()           # 노란 안전모 삽질러 등장
snow.fall(300)         # 눈 300송이(그중 한 송이는 금색)
me.삽질(365)            # 삽질 365번 = 365일. 12달치 흙이 달마다 날 수만큼 쌓인다
countdown(3)           # 3 · 2 · 1
year += 1              # ✕ 새해 진입 실패 — 사유: "수고했어" 누락
say("수고했어")         # 보완 완료 → 흙더미가 금빛으로, 헛삽질 12 → 0
year += 1              # ✓ 2027
fireworks(12)          # 달마다 한 발씩 12발, 마지막 한 발은 삽 모양
# 친구에게 보내기
```

| 시간 | 화면 |
|---|---|
| 0.00초 | 완성 장면이 먼저 보인다(금빛 흙더미 · 2027 · 불꽃) + 낚는 말 **"올해 삽질만 했다면 / 6번째 줄에서 에러 납니다"** |
| 0.17–0.87초 | 코드가 전체 선택되고 지워지자 장면이 거꾸로 풀려 빈 밤하늘이 된다 |
| 2.00초 | `year = 2026` → 연도판이 내려앉는다 |
| 3.00초 | `me = 삽질러()` → 삽질러 착지, 손 인사 |
| 4.00초 | `snow.fall(300)` → 눈 |
| 5.25–7.00초 | `me.삽질(365)` → 삽 한 번에 한 달. 흙띠 12개(1월 계획 · 2월 시작 · 3월 어라? … 12월 완성)가 쌓이고, 양옆에서 `삽질 365` · 날짜 · 빨간 `헛삽질 12`가 함께 올라간다 |
| 7.50–8.50초 | `countdown(3)` |
| 9.00초 | `year += 1` → **오류**. 연도판이 반쯤 넘어가다 걸리고, 도장 "새해 진입 실패 / 사유: "수고했어" 누락", 화면에서 색이 빠지고 눈이 느려진다 |
| 10.25–11.7초 | `say("수고했어")` → 도장이 '보완 완료'로 뒤집히고, 말풍선, 확인란 체크, 흙더미가 아래서부터 금빛으로, `헛삽질 12 → 0` |
| 12.00초 | `year += 1` → '철컥' **2027**. 날짜 2027.01.01, 창 이름 `2027.py`, 지평선에 동이 트고 위 글자가 **"헛삽질은 없었습니다 / 올해도 수고 많으셨습니다"** 로 바뀐다 |
| 13.0–14.5초 | `fireworks(12)` → 달마다 그 달의 흙띠에서 한 발씩. 마지막 넷은 금빛 버들, 12번째는 삽 모양 |
| 16.00초 | 마지막 프레임이 첫 프레임으로 이어진다(반복 재생) |

모든 동작은 120bpm(한 박 0.5초) 격자 위에 있습니다. 16초 = 〈석별의 정〉 한 절 8마디.

## 오른쪽 코드는 장식이 아닙니다

화면에 찍히는 글자(`script.js`)를 엔진이 그대로 읽어서(`engine/interp.js` → `engine/timeline.js`) 무대를 그립니다(`engine/stage.js`).

- `me.삽질(365)`를 `100`으로 바꾸면 흙더미가 4월 10일 높이에서 멈춥니다.
- `say("수고했어")` 줄을 지우면 여덟째 줄도 여섯째 줄과 같은 오류가 나고 연도판은 2026에 머뭅니다. 맺는 말도 뜨지 않습니다.
- `fireworks(3)`이면 불꽃이 세 발, `snow.fall(30)`이면 눈이 서른 송이입니다.
- 엔진에 없는 이름(`tree.grow(7)` 등)을 쓰면 그 줄에 진짜 `NameError`가 납니다. 낚는 말의 "N번째 줄"도 대본에서 처음 오류가 나는 줄 번호로 바뀝니다.

부를 수 있는 이름은 `engine/stage.js`의 `REGISTRY`에 있는 것이 전부입니다. "수고했어 없이는 새해로 못 넘어간다"는 규칙도 거기에 있습니다(`'year +='`의 `check`).
다만 화면의 10줄이 프로그램의 전부는 아닙니다. 10줄은 장면 대본이고, 그 대본을 읽어 그리는 엔진(약 2,200줄)이 따로 있습니다.

## 소리 (`source/audio.py`)

소리 파일을 쓰지 않고 전부 NumPy로 합성합니다. 시각은 영상과 같은 시각표(`source/build/events.json`)에서 읽으므로 화면과 어긋나지 않습니다.

- 음악: 저작권이 없는 옛 가락 〈석별의 정〉(Auld Lang Syne) 한 절을 오르골로. 처음에는 가늘게 깔리다가, 9초 오류에서 뚝 끊기고, "수고했어"부터 화음과 함께 돌아옵니다.
- 효과음: 타자, 연도판, 삽질(달마다 한 박자), 카운트다운, 오류음과 도장, 금빛 종, 연도판 '철컥', 불꽃.
- 가락 없는 판(`soundtrack_fx.wav`)을 함께 만듭니다.

## 다시 만들기

```bash
cd source
node render.js            # ../newyear_code_reel_silent.mp4 (약 2분)
python3 audio.py          # ../audio/*.wav → ../newyear_code_reel.mp4, ../newyear_code_reel_fx.mp4
python3 verify.py         # 규격·줄거리·이음매·대본 바꿔 보기·안전 구역·음량 검사
node render.js --still 470 --out-dir ..   # 한 장만 PNG로(표지: f0470.png → cover.png)

node render.js --script 다른대본.js --still 300 --out-dir /tmp/x   # 대본을 바꿔서 한 장
node render.js --no-cold-open --out ../newyear_code_reel_B_silent.mp4   # 첫머리(완성 장면 → 되감기) 없이 빈 무대에서 시작하는 비교판
```

`source/index.html`을 크롬에서 열면 같은 영상이 실시간으로 재생됩니다(클릭: 멈춤/재생, ←→: 한 프레임).

필요: Node.js 18+ 와 Playwright(크로미움) — 없으면 `npm i playwright && npx playwright install chromium`, Python 3.11+ 와 NumPy·Pillow, FFmpeg(libx264).

| 파일 | 하는 일 |
|---|---|
| `script.js` | 화면에 찍히는 대본 |
| `timing.js` | 줄마다 Enter가 떨어지는 박자, 영상 길이, 첫머리 |
| `copy.js` | 위쪽 큰 글자(낚는 말·맺는 말) |
| `engine/interp.js` | 대본 한 줄을 뜻으로 바꾼다(호출·대입·주석·오류) |
| `engine/timeline.js` | 글쇠 하나하나의 시각, 줄이 실행되는 시각, 그 줄이 부르는 효과 |
| `engine/stage.js` | 왼쪽 무대 — 연도판, 삽질러, 흙더미, 계수기, 도장, 말풍선, 불꽃 |
| `engine/editor.js` | 오른쪽 코드 창 — 타자, ✓/✕, 오류 줄, 한 줄 설명 |
| `engine/worker.js` | 삽질러(도형으로 그린 창작 캐릭터) |
| `engine/fx.js`, `engine/util.js` | 눈·불꽃·빛 같은 효과와 공용 도구 |
| `engine/main.js` | 조립, 첫머리 되감기, 위쪽 글자, 소리용 시각표 |
| `render.js` | 헤드리스 크로미움으로 프레임을 한 장씩 그려 FFmpeg로 묶는다 |
| `audio.py`, `verify.py` | 소리 합성, 자동 검증 |

프레임은 시각의 순수 함수입니다(난수는 씨앗 고정, 입자 위치는 닫힌 식으로 계산). 그래서 몇 번을 렌더해도 같은 그림이 나오고, 첫머리에서 장면을 거꾸로 돌릴 수 있습니다.
