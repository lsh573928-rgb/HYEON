# 새해 코드 릴스 — "헛삽질은 없었습니다" (2026 → 2027)

왼쪽은 장면을 매 프레임 글자(ASCII)로 찍은 그림, 오른쪽은 그 그림을 만드는 코드가 디버거처럼 한 줄씩 실행되는 16초짜리 인스타그램 릴스입니다.
그림 파일·소리 파일 없이 전부 코드로 만들었습니다.

| `newyear_code_reel_fx.mp4` | 같은 영상, 가락 없이 효과음만(인스타 앱에서 유행 곡을 덧입힐 때, 또는 음원 자동 인식에 걸릴 때) |

## 화면

**왼쪽 — 장면을 글자로.** 무대(연도판·삽질러·흙더미·눈·불꽃)를 보이지 않는 그림판에 그린 뒤, `engine/newyear.js`의 `ascii()`가
칸마다 밝기를 보고 `' .:-=+*#%@'` 중 하나를, 밝기가 갑자기 바뀌는 곳(윤곽)에는 방향에 따라 `- \ | /`를 골라 그 칸의 색으로 찍습니다.
칸은 8px이고 삽질러 둘레만 6px입니다. 2027이 '철컥' 잠기면 연도판에서 고리가 퍼지며 고리 안쪽부터 칸이 5px로 작아집니다(해상도 업).
달 이름표·계수판·확인란·도장·말풍선처럼 읽어야 하는 글자만 글자로 바꾸지 않고 또렷하게 얹습니다.

**오른쪽 — 디버거 세 칸.**
1. `2026.py` — 장면 대본 10줄. 실행 중인 줄에 막대가 내려가고, 다 끝난 줄에 ✓, 6번째 줄에 ✕와 `← "수고했어" 누락`.
2. `newyear.js` — 그 줄이 부른 **실제 코드**. 화면에 뜨는 글자는 엔진이 돌리는 함수의 원문(`Function.toString`) 그대로입니다.
   막대가 반복문을 돌고, 머리 오른쪽에 지금 값(`d = 212`, `k = 3`, `env.thanked = false`, `cell = 5`, `i = 11`)이 뜹니다.
   대본이 쉬는 동안에는 그림을 글자로 바꾸는 반복문(`for y … for x …`)이 돕니다.
3. 터미널 — 실행 결과, `6 Error: "수고했어" 누락 / at 2026.py:6`, `⏸ 예외에서 멈춤` → `▶ 계속 (2026.py:7)`,
   마지막에 `= 오류 1건 · 헛삽질 0건`. 맨 아래 `frame 285/480 · 67×133칸 · 2,808자`는 그 프레임에서 실제로 센 값입니다.

## 줄거리 (오른쪽 첫 칸의 대본 = `source/script.js`)

```python
year = 2026            # 연도판이 내려앉는다. 밑에는 비어 있는 '수고했어' 확인란
me = 삽질러()           # 노란 안전모 삽질러 등장
snow.fall(300)         # 눈 300송이(그중 한 송이는 금색)
me.삽질(365)            # 삽질 365번 = 365일. 12달치 흙이 달마다 날 수만큼 쌓인다
countdown(3)           # 3 · 2 · 1
year += 1              # ✕ 새해 진입 실패 — 사유: "수고했어" 누락
say("수고했어")         # 보완 완료 → 흙더미가 금빛으로, 헛삽질 12 → 0
year += 1              # ✓ 2027 — 해상도 업
fireworks(12)          # 달마다 한 발씩 12발, 마지막 한 발은 삽 모양
# 수고한 친구에게
```

| 시간 | 화면 |
|---|---|
| 0.00초 | 완성 장면(금빛 흙더미 · 2027 · 불꽃) + 낚는 말 **"올해 삽질만 했다면 / 6번째 줄에서 에러 납니다"** |
| 0.25–1.4초 | 실행이 거꾸로 돌아 빈 밤이 된다. 터미널에 `$ node render.js` |
| 2.00초 | `year = 2026` → 연도판이 내려앉는다 |
| 2.75초 | `me = 삽질러()` → 삽질러 착지, 손 인사 |
| 3.25초 | `snow.fall(300)` → 눈이 쏟아진다 |
| 4.25–7.00초 | `me.삽질(365)` → 코드 창의 `for (let d = 1; d <= n; d++)`가 돌며 `d`가 365까지. 삽 한 번에 한 달, 흙띠 12개(1월 계획 · 2월 시작 · 3월 어라? … 12월 완성) |
| 7.50–8.50초 | `countdown(3)` |
| 9.00초 | `year += 1` → **오류**. 코드 창은 `throw Error('"수고했어" 누락')`에서 빨갛게 멈추고 `env.thanked = false`. 연도판이 넘어가다 걸리고 빨간 도장, 무대의 색이 빠진다 |
| 10.25–11.7초 | `say("수고했어")` → `env.thanked = true`, 도장이 '보완 완료'로, 말풍선, 확인란 체크, 흙더미가 아래서부터 금빛, `헛삽질 12 → 0` |
| 12.00초 | `year += 1` → '철컥' **2027**. `cell = 5` — 고리가 퍼지며 그림이 촘촘해진다. 위 글자가 **"헛삽질은 없었습니다 / 올해도 수고 많으셨습니다"** |
| 13.0–14.5초 | `fireworks(12)` → 쏘는 순서 = 코드 창의 `i` = 그 달의 흙띠. 12번째는 삽 모양 |
| 14.7초 | `# 수고한 친구에게` → 무대에도 같은 말 |
| 16.00초 | 마지막 프레임이 첫 프레임으로 이어진다(반복 재생) |

모든 동작은 120bpm(한 박 0.5초) 격자 위에 있습니다. 16초 = 〈석별의 정〉 한 절 8마디.

## 오른쪽 코드는 장식이 아닙니다

- 대본이 부르는 이름이 실제로 하는 일은 `engine/newyear.js`의 `C`에 있고, 화면 둘째 칸에 뜨는 것이 바로 그 코드입니다.
  예를 들어 "수고했어 없이는 새해로 못 넘어간다"는 `C['year +=']`의 `if (!env.thanked) throw Error('"수고했어" 누락')` 한 줄입니다.
- 왼쪽 그림을 글자로 바꾸는 `ascii()`도 같은 파일에 있고, 매 프레임 실제로 돌아갑니다.
- `me.삽질(365)`를 `100`으로 바꾸면 흙더미가 4월 10일 높이에서 멈춥니다. `say("수고했어")` 줄을 지우면 여덟째 줄도 같은 오류가 나고 연도판은 2026에 머뭅니다.
  `fireworks(3)`이면 세 발, `snow.fall(30)`이면 서른 송이. 없는 이름(`tree.grow(7)`)을 쓰면 그 줄에 진짜 `NameError`가 나고, 낚는 말의 "N번째 줄"도 따라 바뀝니다.
- 화면의 10줄이 프로그램의 전부는 아닙니다. 10줄은 장면 대본이고, 장면을 그리는 엔진(`source/engine/`)이 따로 있습니다.

## 소리 (`source/audio.py`)

소리 파일 없이 전부 NumPy로 합성합니다. 시각은 영상과 같은 시각표(`source/build/events.json`)에서 읽어 화면과 어긋나지 않습니다(측정 결과 어긋남 0ms).

- 음악: 저작권이 없는 옛 가락 〈석별의 정〉(Auld Lang Syne) 한 절을 오르골로, 120bpm. 첫 음이 0초에 울리고, 처음에는 가늘게 깔리다가
  9초 오류에서 뚝 끊겨 무음, "수고했어"(10.5초, 6마디 첫 박)부터 화음·셰이커와 함께 돌아와 14.5초 으뜸음으로 끝납니다.
- 코드 소리(오른쪽): 줄이 실행될 때 '톡'과 짧은 음(줄마다 한 음씩 오른다), 디버거 막대가 움직일 때 작은 틱, 오류 '부—', 성공 '딩'.
- 무대 소리(왼쪽): 연도판, 삽질(달마다 한 박자), 카운트다운, 오류음과 도장, 금빛 종, '철컥', 불꽃(가락 밑으로 눌러 둔다).
- -14.0 LUFS, 트루 피크 -1.8 dBTP(AAC 뒤). 가락 없는 판(`soundtrack_fx.wav`)을 함께 만듭니다.

## 검증 (`source/verify.py`)

`python3 verify.py` — MP4를 다시 풀어 낸 프레임으로 53가지를 검사합니다(전부 통과, 약 30초). 모든 위치·시각은 `build/events.json`에서 읽습니다.

| 묶음 | 보는 것 |
|---|---|
| A 규격 | H.264 High·yuv420p·1080×1920·30fps·480장·16.000초·bt709·faststart, AAC 48kHz 2ch |
| B 줄거리 | 연도판 하늘색 → 금색, 걸릴 때 빨개짐, 확인란 회색 → 빨강 → 금색, 흙더미 높이·흙색 → 금색, 실패 때 색 빠짐, 해상도 업(글자 줄 간격 ×1.59), ✓/✕·실행 막대·터미널 상태 줄 순서, 코드 창이 움직임, 위 글자 바뀜, 불꽃 12발·삽 모양 1발·쏘는 순서 |
| C 이음매 | 마지막 프레임 → 첫 프레임 차이가 보통 이웃 프레임 수준 |
| D 결정성 | 같은 프레임을 두 번 그려도 화소가 같고, MP4가 지금 코드로 그린 것과 같다 |
| E 대본이 영상을 움직인다 | `me.삽질(100)` → 4월 10일 높이, `say` 줄 삭제 → 2026에 머묾, 없는 이름 → NameError와 낚는 말 줄 번호, `fireworks(3)` → 3발, `snow.fall(30)` → 눈이 적다 |
| F 안전 구역 | 인스타 오른쪽 단추(x 940~) 밑에 코드 글자 없음, 창 안에 글자, 머리 값과 함수 이름 안 겹침, 위 220px·4:5 자르기 |
| G 소리 | -14.0 LUFS, 트루 피크 -1.8 dBTP, 오류 뒤 정적이 26.7dB 더 조용함, 효과음판도 규격 같음 |

## 다시 만들기

```bash
cd source
node render.js            # ../newyear_code_reel_silent.mp4 (약 2분)
python3 audio.py          # ../audio/*.wav → ../newyear_code_reel.mp4, ../newyear_code_reel_fx.mp4
python3 verify.py         # 규격·줄거리·이음매·대본 바꿔 보기·안전 구역·음량 검사
node render.js --still 465 --out-dir /tmp/x   # 한 장만 PNG로(표지는 f0465)

node render.js --script 다른대본.js --still 300 --out-dir /tmp/x   # 대본을 바꿔서 한 장
node render.js --raw --still 300 --out-dir /tmp/x                  # 왼쪽을 글자로 바꾸기 전 그림 그대로
node render.js --no-cold-open --out ../newyear_code_reel_B_silent.mp4   # 첫머리 없이 빈 무대에서 시작하는 비교판
```

`source/index.html`을 크롬에서 열면 같은 영상이 실시간으로 재생됩니다(클릭: 멈춤/재생, ←→: 한 프레임).

필요: Node.js 18+ 와 Playwright(크로미움) — 없으면 `npm i playwright && npx playwright install chromium`, Python 3.11+ 와 NumPy·Pillow, FFmpeg(libx264).

| 파일 | 하는 일 |
|---|---|
| `script.js` | 장면 대본(오른쪽 첫 칸) |
| `timing.js` | 줄마다 실행되는 박자, 영상 길이, 첫머리 |
| `copy.js` | 위쪽 큰 글자(낚는 말·맺는 말) |
| `engine/newyear.js` | 대본이 부르는 이름들이 하는 일 + 그림을 글자로 바꾸는 `ascii()` (오른쪽 둘째 칸에 뜨는 코드) |
| `engine/interp.js`, `engine/timeline.js` | 대본 한 줄을 뜻으로 바꾸고, 줄마다 newyear.js를 실제로 불러 실행 결과를 남긴다 |
| `engine/stage.js` | 왼쪽 무대 — 연도판, 삽질러, 흙더미, 계수기, 도장, 말풍선, 불꽃 |
| `engine/editor.js` | 오른쪽 디버거 세 칸 — 대본, 실행 중인 코드와 값, 터미널 |
| `engine/worker.js` | 삽질러(도형으로 그린 창작 캐릭터) |
| `engine/fx.js`, `engine/util.js` | 눈·불꽃·빛 같은 효과와 공용 도구 |
| `engine/main.js` | 조립 — 무대를 글자로 찍기, 첫머리 되감기, 위쪽 글자, 소리용 시각표 |
| `render.js` | 헤드리스 크로미움으로 프레임을 한 장씩 그려 FFmpeg로 묶는다 |
| `audio.py`, `verify.py` | 소리 합성, 자동 검증 |

프레임은 시각의 순수 함수입니다(난수는 씨앗 고정, 입자 위치는 닫힌 식으로 계산). 그래서 몇 번을 렌더해도 같은 그림이 나오고, 첫머리에서 장면을 거꾸로 돌릴 수 있습니다.
